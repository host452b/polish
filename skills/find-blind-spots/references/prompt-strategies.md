# Prompt strategies：取舍与组合

供维护者比较策略、设计评估或解释依据时读取。日常执行以 [SKILL.md](../SKILL.md) 为准，不额外运行这份文档里的策略目录。通俗步骤用中文，专业术语保留英文。

## 组合原则

本 skill 的目标是发现能改变行动的缺口，不是制造更多推理文本。采用 `目标与证据 → 候选及反证 → 有限比较 → 最小验证 → 输出检查`；每阶段只传递必要结论和证据状态，不默认启动多轮模型调用、多 Agent 或额外付费操作。

研究启发与本 skill 的工程化规则分开：没有在目标模型和真实任务上做配对评估，就不声称这些组合提高了准确率、降低了幻觉率或没有延迟成本。

## 融入或保留的策略

| 策略 | 本 skill 的具体用法 | 适用边界 |
| --- | --- | --- |
| Layered Prompt + Prompt Chaining | 按目标、证据、筛选、验证、输出分层；跨阶段保留 Evidence ledger 的来源与不确定状态 | 这是单次工作流的结构，不声称只是写下多个步骤就完成了多次独立模型调用 |
| Self-Contrast | 比较候选与最强替代解释，寻找会撤回或缩小主发现的证据 | 采用证据导向的工程化改写，不等于复现论文；可保留原结论，不强制反转 |
| ReAct | 有工具时，用最小只读查询取得真实 Observation，再更新命题状态 | 无工具时给验证建议，不编造 Action/Observation；授权边界保持不变 |
| Knowledge Time-Stamp | 为证据记录日期、版本和适用范围，优先检查当前适用性 | 时间较新不自动更可靠；不能通过提示词改写模型的 Knowledge cutoff |
| Tree of Thoughts 的有限借鉴 | 仅在候选竞争时比较 2–3 个不同机制，遇到反证才切换 | 不执行完整树搜索，不要求固定路径数量或主观打分；这不是论文 ToT 的等价实现 |
| Mirror Test 的有限借鉴 | 一次 Contract check，核对证据一致性、验证动作及 ASCII 输出 | 修正可指出的错误，交付完整答案；自评不是外部验证，也不保证提升 |
| Flipped Interaction | 只有无法取得且会改变首要建议的信息才询问；沿用正文的问题数量限制 | 不固定先问三题，已有材料足够时直接完成任务 |
| Role-Rule Double Bind 的有限借鉴 | 用实际职责视角生成候选，如运行责任、用户结果、维护成本 | 不虚构专家资质或模拟多名专家形成权威共识；无需“违反即回答错误”的口令 |
| Few-Shot | 已有对应机制的参考示例可解释动作与输出边界 | 示例只示范方法；若按任务选例，来源必须已经核验，不能用本轮生成答案自证正确 |

## 不默认叠加的策略

| 策略 | 取舍原因 |
| --- | --- |
| Prompt Repetition | 不重复整份 skill 2–3 次；输出规则保留单一来源。论文主要评估非推理设置，不能外推为当前长上下文工作流必然获益或零成本 |
| Option-First MCQ | 当前任务是开放式发现，没有固定正确选项；先固定选项可能遗漏更合适的候选。用户明确给出封闭选项时按其契约处理，不宣称前置选项普遍消除位置偏差 |
| Self-Consistency | 原方法依赖实际多路径采样及答案聚合；三个同源摘要不等于独立证据，也不能靠共识确认用户缺口。当前 skill 不默认扩展成多次调用 |
| Symbolic Placeholder | ASCII 表格、字段与缺失值规则已经确定；没有机器解析契约时不新增 `answer` 标记，避免破坏用户要求的格式 |
| Temp-Decay Sampling | 自然语言指令不提供逐 token 调温能力；需要运行时解码控制。这里仅分开发现候选与证据筛选，不声称模拟了实际温度变化 |
| Chain-of-Thought | 可以进行必要的任务分解，但不要求展示逐步内部推理；用户需要结论、关键依据和可检验动作 |
| Meta-Prompting | 属于维护和评估阶段，不在每次执行中让 skill 自行重写、放宽自己的规则 |
| Dynamic Few-Shot 的自选正确答案版本 | 没有可靠反馈时无法把自身生成结果直接标成正确样本；容易把未经证实的内容带入下一轮 |

`Self-Contrast` 示例中“每条评分 1–5，若总分 > 0 则修正”会使非空列表必然触发修改；它不是证据判据。本 skill 用支持、反驳、无法区分三个可解释结果替代。

## 已核验的一手来源

核验日期：2026-10-09。以下描述仅覆盖论文中的方法或实验范围，不是对本 skill 的效果承诺。

- [Leviathan, Kalman & Matias (2025), Prompt Repetition Improves Non-Reasoning LLMs](https://arxiv.org/html/2512.14982v1)：2025-12-17 提交，Google Research。主要结果来自非推理设置；全文也报告推理设置下较小且混合的收益，以及部分长输入增加延迟的例外。不是“Google 2024、所有任务无成本提升”。
- [Zhang et al. (2024), Self-Contrast](https://arxiv.org/abs/2401.02009)：通过不同解答视角的分歧形成复查清单，ACL 2024；不支持把任意“列三条反证并加分”模板等同于该方法，也不据此接受“Meta 2025、降低幻觉约 24%”的归属与数字。
- [Wang et al. (2022 preprint), Self-Consistency Improves Chain of Thought Reasoning](https://arxiv.org/abs/2203.11171)：从多条采样路径聚合答案，研究算术与常识推理任务；不是在同一回复中写三段类似答案就获得独立证实。
- [Yao et al. (2023), Tree of Thoughts](https://arxiv.org/abs/2305.10601)：包含候选路径探索、评估及必要时的回溯；本 skill 的有限候选比较只是取其思路，不声称复现实验结果。
- [Yao et al. (2022 preprint; 2023 revision), ReAct](https://arxiv.org/abs/2210.03629)：交替进行推理与环境交互；本 skill 只将其用于授权范围内的证据查询，不输出内部推理轨迹。
- [Huang et al. (2023), Large Language Models Cannot Self-Correct Reasoning Yet](https://arxiv.org/abs/2310.01798)：在所测设置中，无外部反馈的自我修正可能不可靠甚至退化。此结果也不能外推为所有后续模型都无法自我修正；这里用它提醒自检不等于事实验证。

其余“Microsoft 降错 18%”“CMU 提升 5–9 点”“Anthropic 92%→98%”“Stanford 降幻觉 15%”“Tsinghua F1 +2.3”等说法缺少本次已核验的具体论文与实验条件，不作为本 skill 的设计或效果依据。没有逐项证伪，不应反向声称这些研究必然不存在。
